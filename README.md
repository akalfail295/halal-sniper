# 👑 Halal Sniper Ultra Pro

محفظة تداول تجريبية (Paper Trading) لأسهم وصناديق أمريكية متوافقة مع الشريعة، مبنية على Streamlit.
ما تنفذ صفقات حقيقية، وما تعتبر نصيحة استثمارية، والفحص الشرعي فيها تقريبي وليس فتوى.

## التشغيل على جهازك

```bash
pip install -r requirements.txt
streamlit run app.py
```

بعدها افتح `http://localhost:8501`.

## الإعدادات السرية (اختيارية)

انسخ `.streamlit/secrets.toml.example` باسم `.streamlit/secrets.toml` وعبّي اللي تحتاجه:

| المفتاح | الفائدة |
|---|---|
| `APP_PASSWORD` | كلمة سر للدخول (ضرورية إذا التطبيق منشور على الإنترنت) |
| `TELEGRAM_TOKEN` و `TELEGRAM_CHAT_ID` | تنبيهات تيليجرام + بوت أوامر (`/status` `/positions` `/close` ...) |
| `ANTHROPIC_API_KEY` | زر «🤖 تحليل ذكي» بالرادار (تلخيص الأخبار وشرح الإشارة بالعربي) |

## 📱 التشغيل على الجوال (Streamlit Cloud — مجاني)

التطبيق موقع ويب، ما ينزل كملف على الجوال. ترفعه مرة وحدة على الإنترنت وتفتحه من متصفح الجوال.
كل شخص يسوي هالخطوات بحساباته الخاصة، فكل نسخة لها رابطها وبياناتها وكلمة سرها، وما تتدخل بالثانية.

1. **فك الضغط** عن ملف الـ zip على الكمبيوتر.
2. **GitHub:** سوّ حساب مجاني في github.com ← زر **New repository** ← اكتب اسم مثل `halal-sniper`
   واختر **Private** ← **Create repository**.
3. **ارفع الملفات:** بصفحة المستودع اضغط **uploading an existing file** واسحب **كل محتويات** المجلد
   (مع مجلد `.streamlit` و`views` و`sniper`) ← **Commit changes**.
4. **Streamlit:** ادخل share.streamlit.io وسجّل دخول بحساب GitHub ← **Create app** ← اختر المستودع،
   والفرع `main`، والملف الرئيسي `app.py`.
5. **كلمة السر:** قبل النشر اضغط **Advanced settings** وحط بخانة **Secrets**:
   ```toml
   APP_PASSWORD = "كلمة سر خاصة فيك"
   ```
   (وإذا تبي تيليجرام أضف `TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID`) ← **Deploy**.
6. بعد دقيقتين يطلع لك رابط مثل `https://xxxx.streamlit.app`. افتحه من الجوال:
   - **آيفون:** Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
   - **أندرويد:** Chrome ← القائمة ⋮ ← **إضافة إلى الشاشة الرئيسية**.
7. أول مرة: افتح صفحة **🧪 الباك-تست** وشغّله عشان تنفتح بوابة الجدوى.

> ⚠️ **حفظ البيانات:** الخطة المجانية تمسح ملفات التطبيق إذا انعاد تشغيله أو نام بعد فترة بدون زيارات،
> يعني ممكن ترجع المحفظة للصفر. نزّل نسخة احتياطية من **⚙️ الإعدادات ← النسخ الاحتياطي** كل فترة،
> وارفعها بنفس المكان إذا انمسحت. الحل الدائم ربط التطبيق بقاعدة بيانات أونلاين (مثل Supabase).

## الصفحات

| الصفحة | المحتوى |
|---|---|
| 🏠 الرئيسية | حالة السوق، مؤشرات المحفظة، آخر الأحداث، إشارات اليوم |
| 🎯 الرادار | فحص 8 فواصل زمنية، جدول النقاط، شارت كامل (VWAP/SMA/فوليوم/RSI/MACD/دعم ومقاومة)، تذكرة أمر فوري أو معلق |
| 💼 المحفظة | بطاقات حية، إغلاق كامل أو جزئي، تعديل الوقف والهدف والملاحظات |
| ⏳ الأوامر والمراقبة | أوامر معلقة (اختراق/تراجع) + قائمة مراقبة بتنبيهات سعر |
| 📊 الأداء والسجل | مقارنة مع SPY، التراجع، خريطة الأرباح الشهرية، تفصيل حسب السهم/القطاع/الإطار/السبب، Sharpe، يوميات التداول، تصدير CSV/Excel |
| 🧪 الباك-تست | اختبار خارج العينة، مونتي كارلو، اختبار ثبات الإعدادات، مقارنة قالب الترند |
| 📡 سجل الإشارات | نتائج الإشارات بعد صدورها |
| ☪️ الشريعة والزكاة | فحص نسب AAOIFI (متوسط 24 شهر) + النشاط، تطهير الأرباح، حاسبة الزكاة بالنصاب |
| ⚙️ الإعدادات | المخاطرة والتكاليف، الأتمتة، تيليجرام، النسخ الاحتياطي والاستعادة، التصفير |

## هيكل الكود

```
app.py            نقطة التشغيل والتنقل
ui.py             أدوات الواجهة المشتركة (RTL، الدخول، البطاقات)
views/            صفحة لكل ملف
sniper/           المنطق بدون واجهة:
  data.py         بيانات Yahoo Finance + كاش
  indicators.py   المؤشرات الفنية
  signals.py      نظام النقاط والفحص
  backtest.py     الباك-تست
  engine.py       محرك المحفظة والحماية والأوامر
  monitor.py      المراقب الخلفي والمهام المجدولة
  halal.py        الفحص الشرعي والتطهير والزكاة
  analytics.py    مقاييس الأداء
  charts.py       الرسوم
  notify.py       تيليجرام
  ai.py           التحليل الذكي (اختياري)
tests/            اختبارات آلية
backup_original/  الملف الأصلي قبل التطوير
```
